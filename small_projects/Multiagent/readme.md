### State 

* What starts the process? -> user query
* What does the Researcher produce? -> a list of research result (raw information for web)
* What does the Analyst produce? -> A filter, structured summary of what is actually relevant from search result
* What does the Writer produce? -> The research report in a clean readable format
* What does the Critic produce? -> Feedback from the report (good? missing? improvement?)
* What does the Orchestrator do? -> Which step the workflow is currently on? Track on how many revision cycles have happened?
